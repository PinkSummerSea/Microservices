# Microservices

A hands-on learning project exploring a microservices-based application using C#/.NET, Docker, and Kubernetes.

The repository contains two services, `PlatformService` and `CommandService`, together with Kubernetes configuration files. The project focuses on understanding service boundaries, local containerized development, and Kubernetes deployment concepts.

## Tech

- C#
- .NET / ASP.NET Core
- Docker
- Kubernetes

## Repository Structure

- `PlatformService` — platform-related service
- `CommandService` — command-related service
- `K8S` — Kubernetes manifests and configuration
